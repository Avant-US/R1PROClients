# r1pro_chassis Python 依赖清单（pip 装到 .venv 内）
#
# 用法：
#   1. 先按 install.sh 创建 venv 并注入 Jetson torch 路径
#   2. 然后才能跑：.venv/bin/python -m pip install -r requirements.txt
#
# ⚠️ 注意：本文件只列「应该装到 venv 内」的包。
#    还有 9 个包（torch / websockets / msgpack / omegaconf / loguru /
#    hydra-core / pydantic / fastapi / uvicorn / typing_extensions）
#    不装到 venv，而是通过 .pth 文件从 ~/.local/lib/python3.10/site-packages
#    借用 Jetson 上已有的安装。详见 requirements-system.txt。
#
# ⚠️ 必须按这个顺序装，否则 pip 会尝试拉 x86 版 torch 进来污染 venv。
#    install.sh 已经处理好了顺序。
